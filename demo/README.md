# Synthetic continuity walkthrough

These two files are original, synthetic demo material for storyIsStraight.

1. Open the hosted app or run it locally.
2. Choose **Add pages** and import `episode-01-canon.txt` as **Canon source**.
3. Lock the explicit facts you want to protect.
4. Import `episode-02-revision.txt` as **Incoming revision**.
5. Run **Check continuity**.
6. Inspect the source-backed findings and downstream impact map.

The revision intentionally breaks four facts: Jonah's death, Maya's wrist injury, the phone's dead state, and the timing of the locker-code reveal.
